Privacy Policy

Draft for review · November 3, 2026

Publisher review required

This is a working draft, not a finalized privacy disclosure. The publisher must verify actual data flows, service providers, retention, deletion procedures, and a private support contact before using this page for a Chrome Web Store submission.

About Start Link

Start Link is an independent browser extension designed to organize LinkedIn prospects, outreach campaigns, and related conversations. It is not affiliated with or endorsed by LinkedIn.

Information processed

Depending on features enabled, the extension may process professional profile names, job titles, company information, profile URLs, connection statuses, message contents, outreach activity, campaign configurations, and user preferences. Account features may involve identifiers and authentication tokens.

Purposes

Information is processed to support prospect organization, user-configured campaign workflows, connection and reply tracking, reminders, and workspace functionality.

Storage and external services

Workspace information may be stored in the browser. Optional account, synchronization, and integration features may communicate with external services, including Supabase or other user-connected providers. The publisher must confirm and disclose which information is transmitted to each service before final publication.

User controls

Users can manage campaign settings and pause outreach. Export and deletion functionality may vary by version. Uninstalling the extension does not necessarily delete records previously synchronized to external services.

Retention and security

Retention periods, access controls, and deletion handling are under review. This draft does not promise end-to-end encryption or automatic deletion of all external records.

Contact

For privacy inquiries, access requests, or data deletion requests, email giftedsonbagh@gmail.com. You can also find Start Link on LinkedIn. Please avoid sharing passwords or authentication tokens.
