Privacy Policy

Effective November 3, 2026 · Start Link browser extension

1. About Start Link

Start Link is an independent browser extension for organizing LinkedIn prospects, outreach lists, campaigns, follow-ups, and conversations. Start Link is not affiliated with or endorsed by LinkedIn. This policy describes the data handled by the Start Link v6.33.0 extension and its optional connected features.

2. Data processed

When you use relevant features, Start Link may process names, job titles, companies, LinkedIn profile URLs, publicly visible professional profile details, prospect notes, lists, connection status, outreach history, messages and replies, campaign rules, scheduled actions, and extension preferences. Optional accounts process email addresses and authentication/session information. Optional integrations may also process contact email addresses and phone numbers where available.

3. How data is used

Data is used to populate your prospect workspace, maintain lists and conversation context, perform outreach actions that you configure, schedule follow-ups, display reminders and reports, and provide account or integration features you choose to activate. Start Link interacts with LinkedIn pages to support these user-requested functions.

4. Local storage

Start Link stores workspace records and settings in browser extension storage on your device. Some interface preferences may be stored locally in the dashboard. Removing the extension may remove locally stored extension data, depending on browser behavior. Back up or export important information before uninstalling.

5. Optional cloud accounts and backups

If you enable Start Link account and synchronization features, the extension communicates with a Supabase-backed service to authenticate your account and manage cloud backup and restore. The reviewed extension encrypts workspace backup content on your device using AES-GCM before upload; encryption key material is derived in the extension. Account-related metadata and authentication traffic are not covered by the workspace-backup encryption claim. The cloud service may process account identifiers, authentication information, and encrypted backup data to operate these features. Do not assume that an encrypted backup makes every connected feature end-to-end encrypted.

6. Optional AI features

If you configure AI assistance and provide an API key, Start Link can send relevant prompts, prospect context, and conversation content to your selected provider: OpenAI, Anthropic, or Google Gemini. The provider processes those requests under its own terms and privacy policy. Do not submit sensitive or confidential information unless you are authorized to do so.

7. Optional third-party integrations

When you configure and use a supported integration, Start Link may transmit the contact and workspace fields necessary for that action to the selected service. The reviewed extension includes integration code for external contact-enrichment and CRM services. Such providers have their own data-handling practices. Integration access and available features depend on your configuration and permissions. This policy does not claim that every possible integration is enabled by default.

8. Optional paired web dashboard

Start Link can exchange workspace information with its supported companion website when the pairing feature is used. Treat pairing codes and account credentials as sensitive. Only pair with a website you trust.

9. Retention, control, and deletion

Local records remain available until you remove them using available workspace controls, clear extension data, or uninstall the extension, subject to browser behavior. Cloud data remains subject to the account and backup lifecycle. The reviewed extension offers an account-deletion action that requests deletion through its backend and informs users that local data on their computer remains. The backend's complete deletion timing, backups, and retention rules have not been independently verified. To request assistance with access or deletion, email the address below. Third-party providers may retain data under their own policies.

10. Security

Start Link uses browser extension storage, HTTPS connections to configured services, and client-side encryption for optional workspace cloud backups. No software or internet transmission can be guaranteed completely secure. Protect your device, connected accounts, API keys, and pairing credentials.

11. Your responsibilities

Use Start Link only with information and accounts you are authorized to access. Follow applicable privacy, marketing, and platform rules, including LinkedIn's terms. Start Link is not a LinkedIn product.

12. Changes to this policy

We may update this policy as the extension and its integrations change. The effective date above identifies the current published version.

13. Contact

For privacy questions, access requests, or deletion requests, contact giftedsonbagh@gmail.com. You can also visit the Start Link LinkedIn page. Do not share passwords or API keys in support requests.
